# eypensare.github.io

Personal landing page and open-source portfolio built with a minimal, dark-mode design system.

## 🚀 Stack

- **Framework / Core:** Pure HTML5, Tailwind CSS
- **Icons:** FontAwesome
- **Font:** Inter & JetBrains Mono
- **Deployment:** GitHub Pages

## 🛠️ Key Features

- **Monochrome Dark Theme:** Designed with soft obsidian hues and clean typography.
- **Interactive Terminal Playground:** Built-in CLI widget to interact with system specs and projects.
- **Fully Responsive:** Optimized for desktop and mobile devices.
